Brave'de klasör erişimi kapalı (Brave'in varsayılanı)
  1. Aşağıdaki düğmeyle ayar sayfasını açın (açılmazsa adresi kopyalayıp adres çubuğuna yapıştırın).
  2. File System Access API satırını Enabled yapın.
  3. Alttaki Relaunch düğmesiyle Brave'i yeniden başlatın, sonra bu sayfaya dönüp Klasör seç'e basın.
Bu ayar açılmadan da eklenti çalışır: 4. aşama dosyayı doğrudan yükler, grup dosyaları istenirse panelden tek ZIP olarak indirilir.
